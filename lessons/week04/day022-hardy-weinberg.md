## 1 从个体到群体

从本讲开始进入课程的第二部分。第 3 周讨论了可遗传变异的来源；群体遗传学研究的是这些变异在群体中的组成及其随时间的变化。在这里，**群体**指能够相互交配的同种个体的集合，群体中全部等位基因的总和称为**基因库**（gene pool）（OpenStax §19.1）。Day 001 把微进化定义为群体中等位基因频率与基因型频率的改变；要识别并度量这种改变，首先需要一个基准：如果没有任何进化力量作用，频率会怎样？Hardy–Weinberg 原理回答的正是这个问题。Holsinger 把它比作牛顿第一运动定律，称为群体遗传学的"第一定律"：正如物体在不受外力时保持原有的运动状态，在没有进化力量时，等位基因频率也保持不变（Holsinger, n.d.）。

## 2 等位基因频率与基因型频率

考虑二倍体生物的一个常染色体位点，有两个等位基因 $A$ 与 $a$。设样本中三种基因型的个体数分别为 $N_{AA}$、$N_{Aa}$、$N_{aa}$，总数为 $N$。**基因型频率**（genotype frequency）为

$$P = \frac{N_{AA}}{N}, \qquad H = \frac{N_{Aa}}{N}, \qquad Q = \frac{N_{aa}}{N},$$

**等位基因频率**（allele frequency）则是 $A$ 在全部 $2N$ 个等位基因拷贝中所占的比例：

$$p = \frac{2N_{AA} + N_{Aa}}{2N} = P + \frac{H}{2}, \qquad q = 1 - p = Q + \frac{H}{2}.$$

等位基因频率介于 0 与 1 之间。某一等位基因的频率达到 1 时，称它在群体中被固定（fixed），降为 0 时则称它丢失（lost）；漂变如何导致固定与丢失，将在 Day 029–030 讨论。

基因型频率决定等位基因频率，反之则不然：同一组等位基因频率可以对应许多不同的基因型频率组合。例如 $p = 0.5$ 既可以来自全部为杂合子的群体，也可以来自一半 $AA$、一半 $aa$ 的群体。只有在附加假设（如随机交配）之下，才能由等位基因频率推出基因型频率。

若各基因型在表型上可以区分（例如共显性的分子标记），等位基因频率可以直接计数得到；若存在完全显性，杂合子与显性纯合子无法区分，此时只能借助 Hardy–Weinberg 假设，由隐性表型的频率估计等位基因频率（$\hat q = \sqrt{Q}$）。这样的估计依赖于假设本身是否成立，Holsinger 讲义专门讨论了这一问题。

## 3 Hardy–Weinberg 原理

### 3.1 假设

Hardy–Weinberg 原理建立在一组理想化假设之上：二倍体、有性生殖、世代不重叠；随机交配；群体无限大，因而没有遗传漂变；没有突变、迁移与选择；等位基因按孟德尔规律分离；常染色体位点上两性的等位基因频率相同（Hardy 1908；OpenStax §19.1）。现实群体不可能完全满足这些条件，但正因如此，它可以作为比较的基准。

### 3.2 推导

在随机交配下，形成合子相当于从配子库中随机抽取两个配子。若配子中 $A$ 的频率为 $p$，则下一代合子的基因型频率为

$$P' = p^{2}, \qquad H' = 2pq, \qquad Q' = q^{2},$$

即 $(p + q)^{2}$ 的展开式。这组比例称为 **Hardy–Weinberg 比例**。下一代的等位基因频率为

$$p' = P' + \frac{H'}{2} = p^{2} + pq = p(p + q) = p,$$

与上一代相同。由此得到两个结论：第一，在上述假设下，等位基因频率代代不变；第二，无论初始的基因型频率如何，只要两性的等位基因频率相同，一代随机交配之后基因型频率就达到 Hardy–Weinberg 比例，并此后保持不变。处于这种状态的群体称为处于 **Hardy–Weinberg 平衡**（Hardy–Weinberg equilibrium, HWE）。

同一结果也可以从个体之间的随机交配推出。三种基因型两两交配，各类交配的频率为两种基因型频率之积：$AA \times AA$ 的频率为 $P^{2}$，后代全为 $AA$；$AA \times Aa$（含正反交）的频率为 $2PH$，后代一半为 $AA$；$Aa \times Aa$ 的频率为 $H^{2}$，后代按 1:2:1 分离。把各类交配产生的 $AA$ 后代相加，得

$$P' = P^{2} + PH + \frac{H^{2}}{4} = \left(P + \frac{H}{2}\right)^{2} = p^{2},$$

与配子随机结合的结果相同；对 $Aa$ 与 $aa$ 同样可以验证。两种推导是等价的：前者更简洁，后者更直观地显示了"随机交配"的含义。

第一个结论的意义在 Day 003 已经讨论过：在融合遗传下，变异每代减半，而在孟德尔遗传下，变异本身不会因交配而消失，这为自然选择提供了持久的原材料。

### 3.3 几个直接推论

随着 $p$ 从 0 增加到 1，$AA$ 的频率 $p^{2}$ 单调上升，$aa$ 的频率 $q^{2}$ 单调下降，杂合子频率 $2pq$ 则先升后降，在 $p = 0.5$ 时达到最大值 0.5。稀有等位基因几乎都存在于杂合子中：杂合子与隐性纯合子的频率之比为 $2pq/q^{2} = 2p/q$，当 $q = 0.01$ 时约为 198（练习 2）。这意味着，针对隐性纯合子的选择在等位基因稀有时效率很低，这一点将在 Day 025–026 讨论选择模型时变得重要。

若两性的等位基因频率不同（分别为 $p_m$ 与 $p_f$），第一代的基因型频率为 $p_m p_f$、$p_m q_f + q_m p_f$ 与 $q_m q_f$，杂合子比 Hardy–Weinberg 预期的多；此时两性的等位基因频率都变为 $(p_m + p_f)/2$，再经一代随机交配，才达到 Hardy–Weinberg 比例（练习 3）。

## 4 推广

### 4.1 多等位基因

若一个位点有 $k$ 个等位基因，频率分别为 $p_1, \ldots, p_k$，随机交配下纯合子 $A_iA_i$ 的频率为 $p_i^{2}$，杂合子 $A_iA_j$ 的频率为 $2p_ip_j$，共有 $k(k + 1)/2$ 种基因型；杂合子的总频率为 $1 - \sum_i p_i^{2}$。人类 ABO 血型是一个常用的例子：$I^{A}$ 与 $I^{B}$ 共显性，二者对 $i$ 显性，四种表型的频率可以由三个等位基因频率求出，反过来也可以在 Hardy–Weinberg 假设下由表型频率估计等位基因频率（练习 4）。

### 4.2 X 连锁位点

在 XY 性别决定系统中，雌性有两条 X 染色体，雄性只有一条，雄性对 X 连锁基因是**半合子**（hemizygous）。平衡时，雌性的基因型频率为 $p^{2}$、$2pq$、$q^{2}$，雄性的基因型频率就等于等位基因频率 $p$ 与 $q$。因此 X 连锁隐性性状在雄性中的频率为 $q$，在雌性中只有 $q^{2}$，前者远高于后者。

若两性的等位基因频率起初不同，趋近平衡的过程是振荡的。雄性的 X 染色体来自母亲，雌性的两条 X 分别来自父母，因此

$$p_m' = p_f, \qquad p_f' = \frac{p_m + p_f}{2}.$$

两性频率之差 $d = p_f - p_m$ 每代变为 $d' = -d/2$，即符号交替、绝对值减半；而加权平均 $\bar p = (p_m + 2p_f)/3$ 保持不变，它就是最终的平衡频率（练习 5）。这里的权重反映了群体中雌性携带 X 染色体拷贝数是雄性的两倍。

## 5 Hardy–Weinberg 平衡作为零模型

Hardy–Weinberg 原理的价值不在于现实群体总是符合它，而在于它提供了一个**零模型**（Day 004）：实际观察与预期的偏离，提示某些假设不成立（OpenStax §19.1）。使用这一零模型时需要注意三点。

第一，要区分**基因型比例**与**等位基因频率**这两个层次。Hardy–Weinberg 比例描述的是给定等位基因频率时的基因型组成；一个群体可以在等位基因频率因漂变或选择而改变的同时，每代的合子仍大致符合 Hardy–Weinberg 比例。因此，"符合 Hardy–Weinberg 比例"不等于"没有进化"。

第二，偏离的方向提示可能的原因。纯合子过多可能来自近交或群体结构（Wahlund 效应），杂合子过多可能来自负选型交配或在取样时期之前作用的杂合子优势；但偏离也可能来自技术因素，例如基因型判定错误（Day 021 练习 5）。这些原因及其统计检验将在 Day 023 讨论。

反过来，也可以把第二部分的各讲看作逐一放松 Hardy–Weinberg 假设的结果：非随机交配（如近交）改变基因型比例，但本身不改变等位基因频率（Day 023）；有限群体中的抽样使等位基因频率随机漂变（Day 029）；选择（Day 025–027）、突变（Day 033–034）与迁移（Day 036）则系统地改变等位基因频率；减数分裂中分离比例的偏离同样会改变频率（Day 111）。

第三，Hardy–Weinberg 原理只涉及一个位点。即使每个位点都处于平衡，不同位点之间的关联（连锁不平衡）也不会在一代之内消失，而是按重组率逐代衰减（Day 015、Day 024）。

## 6 案例研究：Hardy（1908）的回答

**问题** 1908 年，有人提出：若短指症由显性基因控制，它在群体中的比例是否会逐渐上升到 3:1？这一疑问来自 Yule（Day 003）。剑桥数学家 Hardy 在给《科学》的一封短信中给出了回答（Hardy 1908）。

**方法** Hardy 假设群体足够大、交配随机、各基因型在两性中均匀分布且生育力相同。他把三种基因型的比例记为 $p : 2q : r$，求得随机交配后下一代的比例为 $(p + q)^{2} : 2(p + q)(q + r) : (q + r)^{2}$（注意这里的 $p$、$q$、$r$ 是基因型比例，与现代记号中的等位基因频率不同）。

**结果** 这一分布与上一代相同的条件是 $q^{2} = pr$；而无论初始比例如何，经过一代随机交配后这一条件总会满足，此后分布保持不变。Hardy 举例说：若最初纯合短指者与正常人之比为 1:10,000，在短指为显性时，第二代短指者的比例约上升为 2:10,000，此后不再改变；若为隐性，第二代则降到约 1:100,000,000（Hardy 1908；练习 6）。显性本身并不会使一个等位基因扩散。

**意义** Hardy 的短信与 Weinberg（1908）同年较早独立发表的结果共同奠定了群体遗传学的出发点（Edwards 2008）。它表明，等位基因频率的改变需要由选择、漂变、突变或迁移等过程来解释，而这些过程正是第二部分各讲的主题。用现代记号表示，Hardy 的条件 $q^{2} = pr$ 等价于 $(H/2)^{2} = PQ$，即 $H^{2} = 4PQ$。

|---|---|---|
| 基因库 | gene pool | 群体中全部等位基因的总和 |
| 等位基因频率 | allele frequency | 某一等位基因在群体中该位点全部等位基因拷贝中所占的比例 |
| 基因型频率 | genotype frequency | 某一基因型的个体在群体中所占的比例 |
| 随机交配 | random mating | 个体之间的交配与其在所研究位点上的基因型无关 |
| Hardy–Weinberg 平衡 | Hardy–Weinberg equilibrium (HWE) | 在无进化力量与随机交配下，基因型频率为 p²、2pq、q² 且代代不变的状态 |
| 复等位基因 | multiple alleles | 同一位点上存在的两个以上的等位基因 |
| 半合子 | hemizygous | 二倍体个体中只有一个拷贝的基因所处的状态，如雄性哺乳动物的 X 连锁基因 |
| X 连锁 | X-linked | 位于 X 染色体上、在两性中拷贝数不同的遗传方式 |
