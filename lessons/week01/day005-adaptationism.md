## 1 什么是适应

### 1.1 两种定义

Day 001 把适应定义为"由自然选择塑造、提高适合度的性状"。细究起来，这一定义包含两个可以分开的要素：**历史**（性状是如何形成的）与**当前效用**（性状现在对适合度有何影响）。由此产生了两种定义（表 1）。

**表 1 适应的两种定义**

| | 历史定义 | 非历史定义 |
|---|---|---|
| 表述 | 性状 T 是对功能 F 的适应，当且仅当 T 是因为执行 F 而被自然选择塑造的（Gould & Vrba 1982） | 在给定环境中，一组表型变体里适合度最高的那个变体就是适应（Reeve & Sherman 1993） |
| 关注的问题 | 性状的起源与选择历史 | 性状当前的适合度效应，以及选择如何维持它 |
| 需要的证据 | 系统发育、化石与功能的历史重建 | 对当前适合度差异的测量 |

两种定义回答的是不同的问题，可能得出不同的结论：一个性状可能当前提高适合度，但最初并不是为这一功能而被选择的。

### 1.2 扩展适应与副产物

Gould 与 Vrba（1982）主张把"适应"限定于**为当前功能而被选择塑造**的性状；对于当前提高适合度、但并非为此而形成的性状，他们提出了新术语**扩展适应**（exaptation）。羽毛常被用来说明这一概念：如果羽毛最初是在与飞行无关的功能（例如保温或展示）上演化的，后来才被用于飞行，那么就飞行而言，羽毛最初是扩展适应。扩展适应形成之后，还可能被进一步的选择改造，发展出针对新功能的次级适应。

**副产物**（by-product）是指本身没有被选择、而是作为其他性状被选择的结果伴随出现的特征。Sober（1984）用一个玩具说明这一区别：一个装置用多层带孔的筛板把小球按大小分开，最终落到底部的都是最小的球，而这些小球恰好颜色相同。装置**选择出了**某种颜色的球（selection *of*），但它**选择的依据**是大小（selection *for*），颜色只是与大小相关的特征。生物学中的对应情形是遗传搭车：与有利突变紧密连锁的中性等位基因频率上升，但选择针对的是有利突变（Day 052）。

## 2 Williams（1966）：审慎使用"适应"

Williams（1966）在《适应与自然选择》中提出，适应是一个"特殊而繁重的概念"，只有在其他解释（偶然、物理规律、其他性状的副产物）不足以说明问题时才应该使用。他以飞鱼为例：飞鱼跃出水面后会落回水中，这对其生存也许至关重要，但它只是飞鱼质量与重力的必然结果，不应被视为适应。这个例子提示我们，应当区分被选择塑造的**功能**与并非由选择造成的**效应**。

Williams 还主张，在解释适应时应优先考虑较低层次的选择（基因与个体），而不是群体层次的选择（Day 156）。他的这本书对 20 世纪下半叶行为生态学与社会进化研究的方法有深远影响。

## 3 Gould 与 Lewontin（1979）的批评

### 3.1 对"适应主义纲领"的指控

Gould 与 Lewontin（1979）把他们批评的研究方式称为"适应主义纲领"（adaptationist programme），并概括了它的几个特征：

1. 把生物体拆解成一个个独立的"性状"；
2. 为每个性状单独提出一个"最优设计"的适应性解释；
3. 当一种适应性解释被否定后，换用另一种适应性解释，而很少考虑非适应性的可能；
4. 满足于合理但未经检验的叙事——他们借用吉卜林童话的名称，称之为"就是如此"故事（just-so stories）。

### 3.2 替代解释

两位作者强调，生物体是一个整合的整体，性状受发育与结构的约束。他们列举了直接适应以外的若干解释：

- **没有选择**：性状的变化由遗传漂变造成；
- **相关的副产物**：性状本身没有被选择，而是对其他性状的选择通过多效性、异速生长等关系带来的结果；
- **选择与适应的脱节**：例如，表型可塑性使个体无需遗传改变即可适应环境；
- **多个适应峰**：不同的适应方案都可行，不同谱系间的差异不一定有适应意义（Day 065）；
- **对已有结构的次级利用**：结构先因建构、发育或历史原因存在，后来才被利用；
- **发育约束**：某些变异难以产生，限制了选择所能达到的结果。

### 3.3 "拱肩"之喻及其争议

论文标题中的"拱肩"（spandrels）指威尼斯圣马可大教堂中圆顶与支撑拱之间的弧面三角区域。两位作者认为，这些区域是把圆顶架在拱上时不可避免的建筑副产物，上面的精美镶嵌画只是对已有空间的利用，不能反过来说明这些区域是"为了"放置镶嵌画而建造的。

这一比喻本身也受到批评：圣马可教堂中的这些结构严格说是**穹隅**（pendentives），而穹隅本身就是承托圆顶的一种工程方案，并非单纯的副产物（Dennett 1995；Houston 1997）。不过，这一批评针对的是比喻，并不影响"性状可能是副产物"这一论点本身。

### 3.4 回应

Mayr（1983）承认适应主义方法有时被误用，但认为它的启发价值足以使其在加以审慎约束后继续使用，并强调随机过程与各种约束本来就使完美适应不可能实现。Reeve 与 Sherman（1993）则认为适应主义研究纲领总体上是成功的，并提出了上文的非历史定义。

## 4 三种适应主义

Godfrey-Smith（2001）与其他哲学家区分了三种在逻辑上相互独立的"适应主义"（另见 *Stanford Encyclopedia of Philosophy* 的 "Adaptationism" 条目）：

| 类型 | 主张 | 性质 |
|---|---|---|
| 经验适应主义 | 自然选择普遍而少受约束，足以解释大多数性状，这些性状在局部是最优的 | 关于自然界的经验主张，可以（在原则上）检验 |
| 解释适应主义 | 解释适应（表观的设计）是进化生物学的核心任务 | 关于学科目标的主张 |
| 方法论适应主义 | 研究一个性状时，从自然选择假说出发是最有效的研究策略 | 关于研究方法的主张 |

接受其中一种并不意味着必须接受其他两种。例如，一个人可以把选择假说当作研究的出发点（方法论），同时认为许多性状实际上并非最优（拒绝经验适应主义）。

## 5 如何检验适应假说

检验适应假说的关键，不是说明某个适应性解释"讲得通"，而是把它与明确的替代假说（漂变、相关反应、约束、可塑性）对照检验。主要途径如下：

| 途径 | 逻辑 | 注意事项 |
|---|---|---|
| 比较法 | 性状是否在相似环境中独立地多次出现（趋同）；性状与环境变量是否相关 | 物种数据不独立，须在系统发育框架中分析（Felsenstein 1985；Day 123） |
| 最优化模型 | 在明确的代价与约束下预测最优性状值，再与观察值定量比较 | 预测失败往往提示模型遗漏了代价或约束，而不必然否定选择的作用（Parker & Maynard Smith 1990） |
| 测量选择 | 在自然群体中测量性状与适合度的关系 | 方法见 Day 062；相关性状可能造成混淆 |
| 操纵实验 | 改变性状或基因型，观察适合度如何变化 | 最直接，但常常只能在少数系统中进行 |
| 分子印记 | 检测基因组中的选择信号 | 方法见第 11 周；须排除人口历史等混杂因素 |

## 6 案例：从突变到存活

Day 001 用岩囊鼠的例子说明了 Tinbergen 四问，并指出"适应意义"需要关于选择的直接证据。Barrett 等（2019）在鹿鼠（*Peromyscus*）中提供了这样一条完整的证据链：

1. **适合度**：在美国内布拉斯加州 Sand Hills 地区，研究者在浅色与深色土壤上建立野外围栏，放入体色各异的鹿鼠，直接测量了作用于体色与 *Agouti* 基因的自然选择——体色与底色匹配的个体存活率更高，这很可能反映了鸟类捕食者对显眼个体的更强捕食。
2. **基因型到表型**：与存活相关的一个 *Agouti* 突变通过改变蛋白质的结合特性使毛色变浅；
3. **因果验证**：基因编辑实验证实，这一突变本身就足以使小鼠毛色明显变浅。

这项研究把一个突变、它的表型效应和它在野外的适合度后果联系了起来，正是检验适应假说所需要的证据类型。

## 思考与练习

1. **（概念）** 判断下列特征最适合归为适应、扩展适应、副产物还是非适应性特征，并说明需要什么证据才能下结论：(a) 如果羽毛起源早于飞行，羽毛对于飞行；(b) 血液的红色；(c) 大熊猫用于抓握竹子的"第六指"（增大的桡侧籽骨，Gould 1980）；(d) 某基因中由遗传漂变固定的一个同义替代。
2. **（概念）** 用 Sober 的"选择出了（selection of）"与"选择的依据（selection for）"分析遗传搭车：在一次选择清除中，被"选择出"的是什么，选择的"依据"又是什么？
3. **（计算）** 最优窝卵数模型（Lack 1947）。设每只雏鸟的存活率随窝卵数 $c$ 线性下降：$s(c) = 1 - ac$，$a = 0.1$。(a) 每窝存活雏鸟数 $P(c) = c(1 - ac)$ 在 $c$ 取何值时最大？(b) 设亲鸟当年的繁殖会降低其未来繁殖价值：总适合度 $W(c) = c(1 - ac) + V_0 - bc$，$b = 0.2$。最优窝卵数变为多少？(c) 野外观察到的窝卵数常常小于 (a) 的预测值。这说明什么？这是否否定了自然选择的作用？
4. **（评论）** Gould 与 Lewontin 的批评主要针对哪一种适应主义？Mayr（1983）的辩护主要捍卫的又是哪一种？
5. **（研究设计）** 以一种植物特化代谢物（例如对植食性昆虫有毒的次生代谢物）为例，写出"它是针对植食者防御的适应"这一假说之外的至少三种替代假说，并为区分这些假说设计比较分析与实验。

<details>
<summary>答案要点</summary>

1. (a) 就飞行而言，最初是扩展适应；若后来羽毛结构又因飞行而被选择改造，则这些改造是针对飞行的次级适应。需要系统发育与化石证据确定羽毛与飞行出现的先后次序。(b) 副产物：血红蛋白的携氧功能受选择，红色是其吸收光谱的物理后果。(c) 籽骨原有其他作用，其增大并用于抓握是选择塑造的结果，因此增大的"第六指"可视为由已有结构改造而来的适应；需要功能形态学与比较证据。(d) 非适应性特征：中性替代，无需选择解释。
2. 被"选择出"的是与有利突变连锁的中性等位基因及其所在的单倍型；选择的"依据"是有利突变本身带来的适合度优势。
3. (a) $P'(c) = 1 - 2ac = 0$，得 $c^* = 1/(2a) = 5$，此时 $P = 2.5$（取整数 $c$ 时也以 5 为最优）。(b) $W'(c) = 1 - 2ac - b = 0$，得 $c^* = (1-b)/(2a) = 4$，此时 $W - V_0 = 1.6$（整数 3 与 5 均为 1.5）。(c) 观察值偏小，说明简单模型遗漏了代价（如亲鸟的繁殖代价）或约束；把代价加入模型后预测与观察可能吻合。最优化模型的"失败"恰恰帮助发现遗漏的因素，并不否定选择的作用。
4. 主要针对经验适应主义（认为选择普遍且足以解释大多数性状），以及方法论适应主义中"只提出适应性解释"的做法；Mayr 主要捍卫方法论适应主义，即选择假说作为研究的出发点具有启发价值。
5. 替代假说示例：该化合物主要针对病原体或紫外线等其他胁迫；它是初生代谢或其他特化代谢途径的副产物；其含量变异主要由漂变或群体历史造成；它曾用于其他功能，后被植食者利用为取食信号（与防御相反的效应）。检验：比较多个独立谱系中化合物含量与植食压力的相关（系统发育比较）；用基因敲除或近等基因系操纵化合物含量，在田间测量取食与适合度；检测相关生物合成基因的选择印记。

## 关键术语

| 中文 | English | 释义 |
|---|---|---|
| 适应的历史定义 | historical definition of adaptation | 性状因执行某功能而被自然选择塑造，才算对该功能的适应 |
| 适应的非历史定义 | nonhistorical definition of adaptation | 在给定环境中，一组表型变体里适合度最高者即为适应 |
| 扩展适应 | exaptation | 当前提高适合度、但并非为当前功能而被选择形成的性状 |
| 副产物 | by-product | 本身未被选择、作为其他性状受选择的结果而伴随出现的特征 |
| 拱肩 | spandrel | Gould 与 Lewontin 借用的建筑术语，比喻作为结构副产物出现的性状 |
| 适应主义 | adaptationism | 关于自然选择与适应在进化解释中地位的一组主张（经验的、解释的、方法论的） |
| 适应主义纲领 | adaptationist programme | Gould 与 Lewontin 所批评的、为每个性状单独寻找适应性解释的研究方式 |
| "就是如此"故事 | just-so story | 合理但未经检验的适应性叙事 |
| 选择出与选择依据 | selection of / selection for | 区分被选择保留下来的特征与选择实际作用的特征 |
| 最优化模型 | optimality model | 在给定代价与约束下预测最优性状值、并与观察比较的模型 |
