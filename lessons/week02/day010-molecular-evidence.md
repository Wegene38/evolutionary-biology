## 1 分子层面的统一性

### 1.1 共享的分子机制

所有已知的细胞生物都以 DNA 为遗传物质，经由 RNA 把遗传信息翻译成蛋白质，并且使用基本相同的遗传密码。Theobald 在《29+ Evidences for Macroevolution》中把这种"生命的基本统一性"列为共同由来的第一个预测：如果所有现生生物源于同一个祖先物种，复制、遗传、催化与代谢的基本机制就应当为所有谱系所共有（Theobald 2012）。

### 1.2 遗传密码的普遍性

遗传密码规定了 64 个三联体密码子与 20 种氨基酸及终止信号之间的对应关系。几乎所有生物都使用同一套**标准遗传密码**（standard genetic code）。Knight 等（2001）认为，标准密码在最后的普遍共同祖先之前就已形成，此后才在许多细胞核谱系与细胞器谱系中发生局部改变。例如，脊椎动物的线粒体把 UGA 读作色氨酸、把 AUA 读作甲硫氨酸，支原体等细菌也把 UGA 读作色氨酸（Elzanowski & Ostell 2024）。这些变异只出现在特定谱系中，是对标准密码的局部修改，在系统发育上嵌套于使用标准密码的类群之内，因此并不意味着存在独立起源的密码。

普遍性之所以能够作为证据，关键在于密码子与氨基酸的对应在很大程度上是任意的。Crick（1968）讨论了"**冻结偶然**"（frozen accident）的设想：一旦密码扩展到全部 20 种氨基酸，任何改动都会同时改变大量蛋白质的序列，因而几乎必然有害，密码由此被"冻结"并传给所有后代。Crick 本人更看重可以检验的立体化学理论，即密码子与氨基酸之间存在化学上的亲和性；如果对应关系完全由化学决定，那么普遍性即使没有共同祖先也可能出现。

后来的研究表明，标准密码并非随机。Freeland 与 Hurst（1998）在计入"转换比颠换更常见"等误差偏向之后发现，在 100 万个随机生成的替代密码中，只有 1 个在减少突变与误译代价方面优于标准密码，这表明密码的结构可能受到**误差最小化**（error minimization）选择的塑造。但最优性并不等于唯一性：即使选择偏好某些类型的密码，仍有大量同样好甚至更好的替代方案（练习 2）。所有生物共享同一套具体的对应关系，包括其中看来任意的细节，最简约的解释仍然是继承自共同祖先。

## 2 分子作为进化史文献

### 2.1 Zuckerkandl 与 Pauling 的设想

Zuckerkandl 与 Pauling（1965b）提出，携带遗传信息的分子本身就是记录进化史的文献。他们把这类分子称为 semantides（信息分子），包括基因、RNA 与多肽。与形态性状相比，分子序列提供了数量巨大、在很大程度上与形态无关的性状。他们在同年的另一篇文章中比较了多个物种的珠蛋白序列，提出了"分子进化钟"的设想（Zuckerkandl & Pauling 1965a；Day 004）。

### 2.2 嵌套层级与独立数据的一致性

共同由来加上分支式的谱系分化，预测性状的分布构成"群中有群"的**嵌套层级**（nested hierarchy），而且由相互独立的数据推断出的历史应当一致（Theobald 2012）。这一预测是可以失败的：如果生物是被独立设计或创造的，没有理由期望不同基因给出相同的分支结构。

Penny、Foulds 与 Hendy（1982）对这一预测进行了定量检验。他们用五种蛋白质的序列分别为同样的 11 个物种构建最简约树，再用 Robinson–Foulds 距离比较这些树之间的差异，结果发现，这些树之间的相似程度远高于随机树之间的预期。作者据此指出，进化理论能够给出可检验的定量预测，因而在原则上是可证伪的。为了说明"偶然一致"有多困难：11 个物种的无根二叉树共有 34,459,425 种（练习 1）。

### 2.3 案例：鲸类与河马

Day 008 介绍了化石证据如何支持鲸类与偶蹄类的亲缘关系。Nikaido、Rooney 与 Okada（1999）用一种与形态和序列比较都相互独立的数据检验了这一结论：他们比较了**短散在核元件**（short interspersed nuclear element, SINE）与**长散在核元件**（long interspersed nuclear element, LINE）在不同物种基因组中的插入位置。SINE 或 LINE 在新位点的整合被视为不可逆事件，因此在同一位点共享的插入是共同祖先的标志。结果表明，河马是鲸类现存最近的亲属，鲸类起源于偶蹄类祖先，而不是中爪兽类祖先。

Hillis（1999）在同期评论中指出，所报道的插入与系统发育完全吻合，支持这类性状同塑水平很低的看法；他同时提醒，SINE 常常随更大片段的缺失而丢失，而且该研究的数据矩阵中有 21% 的元件状态缺失。

## 3 共享的"错误"：假基因与逆转座子插入

### 3.1 证据的逻辑

功能相似可以用功能需求来解释：执行相同功能的分子可能因相同的约束而相似。但在相同位置共享的、没有明显功能的特征则很难这样解释。这类似于检测抄袭：两份文本共享正确的内容并不奇怪，共享同样的错别字才提示抄写关系。Theobald 在第 4 部分"分子证据"中，把冗余假基因、转座子与内源逆转录病毒列为共同由来的分子证据（Theobald 2012）。

### 3.2 假基因：维生素 C 合成能力的丧失

**假基因**（pseudogene）是因突变而丧失功能的基因拷贝。维生素 C 的合成是脊椎动物的祖先性状；在迄今研究过的所有不能合成维生素 C 的物种中，原因都在于编码 L-古洛糖酸-γ-内酯氧化酶的 *GLO* 基因（又称 *GULO*）发生了突变（Drouin et al. 2011）。猿猴类（类人猿亚目，包括人类）的 *GLO* 基因丢失了若干外显子，成为这些物种共享的假基因。Lachapelle 与 Drouin（2011）通过比较具有与不具有功能 *GLO* 基因的谱系，估计灵长类的失活发生在约 6100 万年前，而豚鼠的失活发生在约 1400 万年前。

这一格局提供了两类预测的对照（练习 5）：在猿猴类内部，同一个失活基因由共同祖先传给所有后裔，因此各物种共享失活的位置与时间；在灵长类与豚鼠之间，失活是两次独立事件，因而时间不同。

### 3.3 逆转座子与内源逆转录病毒

逆转录病毒感染细胞后，会把自身基因组的 DNA 拷贝（前病毒）整合进宿主染色体；若整合发生在生殖细胞中，前病毒就会作为**内源逆转录病毒**（endogenous retrovirus, ERV）遗传给后代。SINE、LINE 等**逆转座子**（retroposon）则以"RNA 中间体—逆转录—插入"的方式在基因组中增殖。人类基因组约有一半源自转座元件（International Human Genome Sequencing Consortium 2001）。

对于两个物种在**直系同源位点**（orthologous locus）共享的插入，最合理的解释是插入发生在它们的共同祖先中：即使存在一定的位点偏好，两个谱系独立地在同一位点、以同一方向插入同一元件的概率也极低（练习 3）。前病毒两端各有一段**长末端重复**（long terminal repeat, LTR），整合时两段 LTR 完全相同，此后各自独立积累突变。因此，每个 ERV 位点都能提供两份物种系统发育的独立估计（Johnson & Coffin 1999），两段 LTR 之间的差异还可以用来估计插入的年代（练习 4）。

### 3.4 局限

共享插入是近乎无同塑的性状，但并非完美的性状。第一，SINE 等元件可能随较大的缺失而丢失（Hillis 1999）。第二，插入的位点偏好会提高独立插入同一位点的概率。第三，若某个插入在祖先群体中尚处于多态状态，后裔物种可能随机保留或丢失它，造成与物种树不一致的分布，这就是**不完全谱系分选**（incomplete lineage sorting, ILS；Day 046、Day 121）。因此，个别不一致的插入并不否定共同由来，它们反而记录了祖先群体的遗传多样性。

## 4 普遍共同祖先的形式检验

上述证据大多涉及较近的类群。在细菌、古菌与真核生物三个域的尺度上，水平基因转移十分常见，"生命之树"是否仍是合适的描述本身就有争论（见 Day 107 与 Day 128）。传统的分析又往往预设"序列相似意味着同源"，这使"所有生命源于同一祖先"这一命题本身难以被检验。

Theobald（2010）试图给出一个不预先假定"序列相似即共同由来"的形式检验。他选取了 23 种普遍保守的蛋白质，涵盖三个域各 4 个物种，共 12 个物种；用模型选择方法比较"所有生物源于同一祖先"的**普遍共同祖先**（universal common ancestry, UCA）模型与多种"多个独立起源"模型，结果 UCA 模型得到压倒性的支持。据 Brandeis 大学的报道，UCA 相对于次优模型的支持程度至少为 $10^{2860}$ 比 1（Brandeis University 2010）。

这一检验随即受到质疑。Koonin 与 Wolf（2010）构建了不含系统发育结构的人工比对：每一列都从同一个氨基酸频率库中随机抽取。他们发现 Theobald 的检验仍然偏好 UCA，并认为这种偏好只是序列显著相似的平凡结果。他们的结论是：对普遍共同祖先的"形式证明"尚未实现，而且在原则上可能无法实现，但比较基因组学为这一假说提供的证据是充分的。双方的论证与后续研究将在第 2 周复盘（Day 014）中精读。

本讲与 Day 006–009 合起来说明了一个方法论要点：共同由来的可信度并不依赖某一个"决定性检验"，而是来自多条相互独立的证据，包括同源性、化石序列、生物地理格局、遗传密码、分子系统发育以及共享插入，它们彼此吻合，指向同一个历史。

## 思考与练习

(a) $1/(2G) \approx 1.67 \times 10^{-10}$。(b) $1 - (1 - 1/2G)^{N} \approx N/(2G) \approx 1.67 \times 10^{-6}$。(c) $(1.67 \times 10^{-6})^{7} \approx 3.6 \times 10^{-41}$。(d) 提高 1000 倍后单个插入的概率约为 $1.67 \times 10^{-3}$，7 个全部巧合的概率约为 $3.6 \times 10^{-20}$，仍然可以忽略，结论不变；不过对于少数插入热点，单个共享插入的证据力确实会下降。(e) 不完全谱系分选（祖先群体中的插入多态被不同后裔随机保留或丢失）、插入后的缺失丢失、基因组装配或比对错误，以及跨物种的杂交与基因渗入。
4. (a) 两段 LTR 自插入起各自独立积累突变，两者之间的差异以 $2\mu$ 的速率增长，故 $t = d/(2\mu) = 0.03/(3 \times 10^{-9}) = 1.0 \times 10^{7}$ 年，即约 1000 万年；若漏掉因子 2，会把年代高估一倍（2000 万年）。(b) 插入应晚于猩猩谱系与（人、黑猩猩、大猩猩）共同祖先的分化，而早于大猩猩谱系的分出；若由 LTR 差异估计的年代超出这一区间，说明速率假定有误，或该位点的历史更复杂（例如不完全谱系分选或基因转换）。
5. 功能基因的相似可以由共同的功能约束解释，而共享的失活突变或插入位置不受功能约束，独立出现的概率极低，只能通过继承共享。若失活发生在共同祖先中一次，各后裔物种应共享相同的失活突变（如相同的外显子缺失），失活年代对应共同祖先，且各物种在失活之后另外积累了各自不同的中性突变；若是多次独立失活，各谱系的失活突变通常不同，失活年代也不同，这正是灵长类（约 6100 万年前）与豚鼠（约 1400 万年前）的情形。一个共享插入后来获得功能，并不会削弱论证：功能是插入之后才被利用的，插入本身的位置与序列仍然只能用继承来解释。
6. 竞争假说是：所有生物源于同一祖先（UCA），以及三个域或其组合分别独立起源的多种模型。之所以采用模型选择，是因为直接以"序列相似"为证据会预设相似即同源，陷入循环论证；模型选择在惩罚参数数目的同时比较各模型对数据的解释力。Koonin 与 Wolf 的模拟表明，即使比对中没有系统发育结构，只要各序列在列上相似，该检验也会偏好 UCA；这说明检验结果可能受到比对与序列相似性的驱动，不能视为独立于相似性的"形式证明"。普遍共同祖先的地位因此更适合理解为由多条独立证据共同支持的最佳解释，而不是被单一检验"证明"的定理。

</details>

## 关键术语

| 中文 | English | 释义 |
|---|---|---|
| 标准遗传密码 | standard genetic code | 几乎所有生物共享的 64 个密码子与 20 种氨基酸及终止信号之间的对应关系 |
| 变异遗传密码 | variant genetic code | 某些谱系（如线粒体、支原体）中对标准密码的局部修改 |
| 冻结偶然假说 | frozen accident hypothesis | 认为密码的对应关系大体出于偶然，一旦确立，任何改变都会同时破坏大量蛋白质，因而被固定下来 |
| 误差最小化 | error minimization | 遗传密码的结构使点突变或误译产生的氨基酸替换代价较小的性质 |
| 信息分子 | semantide | Zuckerkandl 与 Pauling 对携带遗传信息的分子（基因、RNA、多肽）的称呼 |
| 嵌套层级 | nested hierarchy | 共同由来与分支分化所预测的"群中有群"的性状分布格局 |
| 系统发育一致性 | phylogenetic congruence | 由相互独立的数据集推断出的系统发育树彼此吻合的程度 |
| 假基因 | pseudogene | 因突变而丧失原有功能的基因拷贝 |
| 逆转座子 | retroposon | 通过 RNA 中间体逆转录后插入基因组而增殖的转座元件，如 SINE 与 LINE |
| 短散在核元件 | short interspersed nuclear element (SINE) | 长度较短、依赖其他元件编码的酶进行逆转座的散在重复序列 |
| 长散在核元件 | long interspersed nuclear element (LINE) | 自身编码逆转录所需蛋白的较长散在重复序列 |
| 内源逆转录病毒 | endogenous retrovirus (ERV) | 整合进生殖细胞基因组并垂直遗传的逆转录病毒前病毒序列 |
| 长末端重复 | long terminal repeat (LTR) | 前病毒两端的重复序列，整合时两段完全相同 |
| 直系同源位点 | orthologous locus | 不同物种基因组中源于共同祖先同一位置的位点 |
| 不完全谱系分选 | incomplete lineage sorting (ILS) | 祖先群体中的多态在后裔物种中随机固定，使基因树与物种树不一致的现象 |
| 普遍共同祖先 | universal common ancestry (UCA) | 所有现生生物源于同一祖先群体的假说 |
| 模型选择 | model selection | 在兼顾拟合优度与模型复杂度的前提下比较多个统计模型的方法 |
