# 进化生物学系统学习

**Evolutionary Biology: A Self-Directed Graduate-Level Course（中文讲义）**

作者：[Wegene38](https://github.com/Wegene38)

本仓库是一门以免费、可合法获取的学术资源为基础的进化生物学系统课程，面向具备本科生物学或相近理工科背景、希望系统掌握进化生物学理论与方法的学习者。课程共 26 周、182 天，每天发布一讲中文讲义，讲义采用作者–年份引用，参考文献经检索核实。

## 课程结构

| 部分 | 周次 | 主题 |
|---|---|---|
| 一 | 第 1–3 周 | 概念基础与证据：定义与解释层次、思想史、进化的证据、树状思维、遗传变异的来源 |
| 二 | 第 4–8 周 | 群体遗传学：HWE 与连锁不平衡、选择、漂变与 Nₑ、群体结构、溯祖理论、中性理论与连锁选择 |
| 三 | 第 9–11 周 | 表型进化与适应：数量遗传学、适应的遗传学、选择的检测与实验进化 |
| 四 | 第 12–13 周 | 物种与物种形成：物种概念、生殖隔离、物种形成基因组学、杂交与多倍化、适应辐射 |
| 五 | 第 14–16 周 | 分子进化与基因组进化：替代模型与分子钟、基因复制与 WGD、新基因、TE、比较基因组学、调控进化 |
| 六 | 第 17–18 周 | 系统发育推断与比较方法：ML 与贝叶斯建树、多物种溯祖、定年、PGLS、OU 与多样化模型 |
| 七 | 第 19–20 周 | 生命史与大进化：生命起源、LUCA、真核起源、主要转变、大灭绝、关键创新 |
| 八 | 第 21 周 | 进化发育生物学：工具包基因、Hox、顺式调控、可塑性与扩展综合 |
| 九 | 第 22–23 周 | 性、生活史、社会行为与共进化 |
| 十 | 第 24 周 | 人类进化：化石、古 DNA、基因渗入与近期适应 |
| 十一 | 第 25–26 周 | 应用与综合：进化医学、病原体、癌症、驯化、保护，模型与研究设计 |

每周 6 讲 + 1 次复盘（第 7、14、21……天）。每日约 60–90 分钟：讲义约 30 分钟，主读或主看材料 30–45 分钟，练习 10–15 分钟。

## 使用建议

1. **每日流程**：先读讲义的学习目标与正文，再完成主读或主看材料，最后独立完成练习，然后对照折叠的答案要点。
2. **原始文献**：每讲至少精读一篇原始文献的摘要、引言与讨论；复盘日完整精读一篇。
3. **文献管理**：将 `references.bib` 导入 Zotero，按周建立分组。
4. **术语复习**：可将 `GLOSSARY.md` 导入间隔重复软件（如 Anki）。
5. **计算实践**：第 7、17、18、26 周包含 msprime、IQ-TREE、R（ape / phytools）与 SLiM 实践，建议提前安装。

## 更新机制

讲义由定时任务每天（爱尔兰时间早上）按 [SYLLABUS.md](SYLLABUS.md) 与 [AUTHORING.md](AUTHORING.md) 生成并发布一讲；文献题录与 DOI 经检索核实，未能核实的会明确标注。第 182 天之后转入每日文献精读的延伸模式。
